# 研究 Idea 与优化方向记录

## 2026-08-27：证据驱动的办公文案交付工作台

- **Idea 描述**：将 Paper Agent 从“论文功能集合”收敛为 OpenPrism Office，面向项目申报、技术报告、研究总结和评审材料，把 brief、资料、证据、AI 草拟、声明/数字核验、人工审批、终稿、提效数据和复用资产组织为一条可追溯交付链。
- **动机**：比赛评分不奖励功能数量，而是要求真实场景、可核验提效、业务化 AI 设计与低成本复用；现有仓库已有证据检索和审查引擎，但未在正式 UI 中形成单一交付闭环。
- **预期效果**：用户能独立完成一份高证据长文档，系统能导出交付包、证据索引、前后效果表、SOP 与评审说明，且不伪造缺失数据。
- **当前状态**：已验证。正式 UI/API、受管状态、规则审核、人工确认导出、模板与参赛文档已落地；自动化门禁已覆盖缺材料、上限规则、安全路径、窄屏和导出闭环。真实业务数据、用户反馈与录屏仍须由参赛团队按事实补齐。
