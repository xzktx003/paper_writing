## 录制要求

- 视频总长不超过 3 分钟。
- 使用受控演示数据时，画面或旁白必须说明“演示数据，不作为真实业务成效”。
- 至少展示一次证据冲突或材料待补风险。
- 不展示 Token、账号、客户名、生产地址、个人信息或未授权截图。
- 保留原始 WebM/MP4、关键截图、时间戳清单和导出 manifest。

实际成片 A：优先上传 `evidence/demo/office-demo-submission.mp4`，ffprobe 核验时长为 163.040 秒，1920×1080、H.264、yuv420p；音轨为 AAC 48 kHz 双声道中文讲解。成片由 3 页开场动画、6 段真实产品实操和 3 页前后对照/效率/边界总结组成；另保留完整 10 张讲解页供截图或答辩使用。实操画面右侧只解释“以前要做什么、现在怎么做、最后得到什么”；77 条逐句字幕随语音定时烧录在独立底部字幕区，不以画面标签冒充字幕。

补充成片 B：`evidence/demo/paper-word-ppt/paper-word-ppt-submission.mp4` 面向论文、Word、PPT 办公专题，ffprobe 核验时长为 148.174 秒，<3分钟；`paper-word-ppt-submission.srt` 含 64 条逐句字幕，逐字稿和封面同目录。它用更白话的方式讲清“写论文、整理 Word、准备 PPT 共用一批资料和依据”，适合评委或办公人员先理解产品价值，再回看 A 视频实操证据。

示例量化边界：A 视频里的 `4处→1任务`、B 视频里的 `学术常见6处→1项目` 和 `重新整理2次→1次后复用` 只表示工作动作结构变化，不是实测时间、生产率或稳定节省比例。真实节省百分比待同口径试点后填写。

原始证据保留为同目录 `office-demo.mp4` 与 `office-demo.webm`，两者均为 73.76 秒；可编辑字幕见 `office-demo-submission.srt`，完整时间轴与讲稿见 `office-demo-submission-transcript.md`，10 张讲解页及元数据见 `slides/` 与 `presentation-slides.json`，19 张关键画面、覆盖率和原始时间戳见 `evidence/demo/coverage.json` 与 `evidence/demo/timestamps.md`。
