## 录制要求

- 视频总长不超过 3 分钟。
- 使用受控演示数据时，画面或旁白必须说明“演示数据，不作为真实业务成效”。
- 至少展示一次证据冲突或材料待补风险。
- 不展示 Token、账号、客户名、生产地址、个人信息或未授权截图。
- 保留原始 WebM/MP4、关键截图、时间戳清单和导出 manifest。

实际成片：优先上传 `evidence/demo/office-demo-submission.mp4`，ffprobe 核验时长为 150.424 秒，1920×1080、H.264、yuv420p；音轨为 AAC 48 kHz 双声道中文讲解。成片由 4 页宏观 PPT、6 段真实产品实操和 4 页成果/意义/推广/边界总结组成。实操画面右侧持续解释“为什么做、本步输入、得到什么、证据边界”；50 条逐句字幕随语音定时烧录在独立底部字幕区，不以画面标签冒充字幕。

原始证据保留为同目录 `office-demo.mp4` 与 `office-demo.webm`，两者均为 73.76 秒；可编辑字幕见 `office-demo-submission.srt`，完整时间轴与讲稿见 `office-demo-submission-transcript.md`，8 张讲解页及元数据见 `slides/` 与 `presentation-slides.json`，19 张关键画面、覆盖率和原始时间戳见 `evidence/demo/coverage.json` 与 `evidence/demo/timestamps.md`。
