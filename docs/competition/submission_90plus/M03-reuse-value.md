# M03 复用价值说明

## 可复用岗位

- 项目申报负责人：申报书、答辩稿、评审说明。
- 技术负责人：技术方案、里程碑总结、研发复盘。
- 科研/产品/运营管理人员：周报、月报、复盘、材料汇总。
- 审核人和 PMO：证据核验、材料一致性检查、提交前风险复核。

## 复用资产

| 资产 | 位置 | 复用方式 |
| --- | --- | --- |
| 写作模板 | `app/templates/office-track-writing/main.md` | 新项目复制后替换 Brief、证据和指标 |

| 90+ 提交包 | `docs/competition/submission_90plus/` | 比赛材料、演示、证据、答辩和合规模板 |

## 学习和部署成本

- 单人培训建议：15-30 分钟，重点是证据等级、人工审批和成效表口径；该时长尚未经过真实用户测量。
- 项目部署：使用现有项目模板，无需新增依赖即可导出材料。
- 权限要求：只处理本项目授权资料；敏感材料需先脱敏。
- 维护方式：由材料负责人维护模板、证据口径和评分规则变更。

## 推广边界

适合高证据、强复核、重复发生的办公材料流程。不适合作为无需核验的一次性闲聊、纯创意文案或涉密资料外发工具。
