# Skill：证据约束办公材料交付

## 触发场景

当用户需要编写项目申报书、技术方案、研究总结、评审说明、答辩稿或会议纪要转正式材料，并要求来源可追溯、人工审批和效果测量时使用。

## 输入

- 任务 Brief：目标、岗位、部门、频率和交付标准。
- 项目内来源：DOCX、PPTX、XLSX、文本或带时间戳会议逐字稿。
- 约束：敏感信息、不可自动发布项、必须人工确认的结论。

## 工作流

1. 登记并解析来源，保留 parser、路径、结构、警告和 provenance。
2. 对待写结论检索证据，分别展示词法、向量和重排分数。
3. 将主张标记为 support、conflict 或 missing；不生成不存在的来源。
4. 形成草稿或修改建议，每个关键结论保留来源和精确位置。
5. 收集人工评论、建议决策和审批事件；没有人工批准不进入发布态。
6. 对完整流程计时并记录质量、采纳、拒绝、频次和版本。
7. 审核材料完整性、信息风险和规则缺口，人工确认后导出提交包与哈希清单。

## 输出要求

- 结论、来源、位置、证据等级和核验状态可对应。
- 缺失、矛盾、推断和已验证状态不得合并。
- 不承诺零错误、全自动、固定提效比例、官方高分或外部平台已投递。
- 最终对外内容必须由指定人员人工批准。
