# 操作与提交核对表

## 演示前

- [ ] 使用脱敏受控项目，不出现 Token、账号、内部地址或真实客户数据。
- [ ] 浏览器可访问，项目、Office 工作台和六阶段导航正常。
- [ ] 演示源文件可以读取，至少包含一个支持证据和一个冲突/缺失证据。
- [ ] 录屏分辨率、光标、字体和中文显示正常。
- [ ] 预计视频总长不超过 3 分钟。

## 演示中

- [ ] 展示一次真实材料导入及 parser 状态。
- [ ] 展示一次混合检索和来源定位。
- [ ] 展示 support/conflict/missing 中至少两种关系。
- [ ] 展示评论/建议和人工审批事件。
- [ ] 展示全成本度量字段，不把 fixture 说成业务数据。
- [ ] 展示一次失败或缺材料状态，证明系统不会伪造成功。
- [ ] 展示导出文件和 manifest。

## 提交前

- [ ] M01-M06、评委指南、复用资产和空白评分表均可打开。

- [ ] 受控演示、测试数据和真实业务数据标识清楚。
- [ ] 真实提效数据能回到逐任务记录、周期和人工确认人；没有则保持待试点。
- [ ] 所有附件完成脱敏和授权复核。
