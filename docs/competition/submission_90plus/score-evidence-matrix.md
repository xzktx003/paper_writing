## 证据定位格式

- 文档：文件名 + 章节。
- 视频：文件名 + 起止时间 + 画面内容。
- 表格：文件名 + 工作表/行列范围。
- 代码：文件路径 + 函数/类名。
- 日志：文件路径 + 时间戳/行号。

## 当前建议

提交前至少补齐：

- 一段 3 分钟内真实操作录屏。
- 一张含 3 个以上样本的真实测量表。
- 一份人工审批或复核记录。
- 一份脱敏检查记录。
- 一份复用试点或培训记录。
