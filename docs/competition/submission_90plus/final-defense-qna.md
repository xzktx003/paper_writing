# 决赛答辩问答准备

| 问题 | 回答要点 | 证据位置 |
| --- | --- | --- |
| 这个作品和普通 AI 写作有什么区别？ | 普通 AI 写作主要生成文本；本作品强制材料登记、证据索引、审阅审批、效果复算和 manifest 导出。 | M01、M02、M06 |
| 如何证明提效？ | 用同类任务基线减去 AI、复核、返工、配置和维护总耗时，并提供样本、周期、质量说明和原始记录。 | M05、pilot-measurement-register.csv |
| 如何防止幻觉？ | 关键主张必须绑定证据编号、来源、位置和等级；E0/E1 不会自动升级为强结论。 | reviewer-guide、score-evidence-matrix |
| 为什么适合办公赛道？ | 场景是高频材料写作和审核，覆盖申报、方案、汇报、评审说明等办公任务。 | M01、M04 |
| 能否推广？ | 可以复制模板、SOP、Skill、指标表和提交包；推广前替换资料库、权限和测量口径。 | M03、M06 |
| 现在是否保证 90 分以上？ | 不能保证官方评分。材料包和连续录屏已经补齐高分结构，90+ 仍取决于真实试点证据和人工评委判断。 | README、score-evidence-matrix |
