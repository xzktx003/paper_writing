# E13 部署、权限与成本说明

- 前端监听地址由环境变量配置并绑定 `0.0.0.0`；对外访问地址按部署网络填写。
- 服务访问使用 Bearer Token；材料和状态保存在受管项目目录。
- 内置 OOXML、BM25、哈希向量、证据图和本地导出不需要外部模型服务。
- AI 草拟、OfficeCLI、PDF/OCR、飞书、邮件和 webhook 是可选能力；没有执行适配器时保持 unavailable/blocked。
- 外部模型、OCR、存储和协作平台费用由部署方按实际用量披露。
- 维护角色建议分为：系统管理员、模板/流程负责人、业务数据确认人和最终审批人。
- 对外材料必须人工批准；本地 published 不是外部投递成功证明。
