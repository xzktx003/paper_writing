# OpenPrism Office 白话办公演示逐字稿

- 产品解决什么：把散落的办公资料，变成能继续修改、能核对来源、能放心提交的成果。
- 谁会用到：经常写方案、纪要、汇报、申报材料，以及负责审核和交付的人。
- 工具接收什么：Word、PPT、Excel、文字记录、任务要求、截止时间和模板。
- 工具交付什么：可编辑材料、依据位置、人工确认记录、耗时记录和完整文件包。
- 能明确看到的改进：四个地方来回切换，变成一个任务连续完成；没有真实数据，就不写节省百分比。
- 真实性边界：没有真实数据，就不写节省百分比；当前只展示能由画面证明的流程变化。
- 字幕形式：讲解内容作为逐句字幕随语音出现，同时提供可编辑字幕文件。
