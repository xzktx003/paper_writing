# 部署复用 SOP

本 SOP 用于证明“可推广性 20 分”：普通目标用户能按材料复现，并理解部署、权限、成本和维护边界。

## 1. 适用岗位

- 科研管理人员。
- 技术负责人。
- 项目申报撰写者。
- 评审材料整理人员。
- 知识密集型办公岗位。

不适合直接复用的场景：没有资料来源、不能人工复核、要求自动提交外部系统、涉及未授权敏感数据的任务。

## 2. 复用资产

| 资产 | 当前位置 | 用途 |
| --- | --- | --- |
| 办公写作模板 | `app/templates/office-track-writing/` | 新建可核验办公文案项目 |
| Brief 模板 | `brief.md` | 固定目标、读者、边界和审核人 |
| 来源登记 | `sources/register.md` | 登记输入材料和权限 |
| 证据索引 | `evidence/index.md` | 绑定主张和证据等级 |
| 效果指标表 | `metrics/effect.csv` | 记录真实提效数据 |
| 复用 SOP | `reuse/SOP.md` | 指导跨项目复用 |
| Skill 草案 | `reuse/Skill.md` | 沉淀提示词和工作流规则 |
| 提交说明 | `submission/README.md` | 准备比赛材料 |

## 3. 首次部署流程

1. 准备一个受管理项目，选择 `office-track-writing` 模板。
2. 填写 `brief.md`，确认目标读者、不可披露内容和审核人。
3. 把可公开或已授权的源材料放入项目目录。
4. 在 `sources/register.md` 登记来源、负责人和是否可用于正式材料。
5. 在右侧“交付”面板登记材料、证据、效果指标和复用资产。
6. 运行证据审核，处理材料缺失、不可读、敏感信息和低证据等级。
7. 人工确认后导出 `submission/`。

## 4. 复用到新场景

复用时只复制流程和模板，不复制旧项目的结论、数字或确认记录。

| 需要重填 | 原因 |
| --- | --- |
| Brief | 不同文案的目标、读者和边界不同 |
| 来源登记 | 新材料权限和事实来源不同 |
| 证据索引 | 旧证据不能证明新结论 |
| 效果指标 | 提效数据必须按新任务重新测量 |
| 人工确认记录 | 审核责任不能跨项目继承 |

## 5. 培训建议

- 15 分钟：解释 Brief、证据等级和人工审批边界。
- 20 分钟：演示来源登记、证据索引和草稿生成。
- 15 分钟：演示审核、风险处理和提交包导出。
- 10 分钟：练习复用到一个新文案任务。

培训完成后，用户应能独立完成一个脱敏项目的 Brief、来源登记、证据登记、审核和导出。

## 6. 维护边界

- 规则文件变化后，需要更新模板、评委说明和规则矩阵。
- 新增文案类型时，需要补对应模板和验收测试。
- 更换模型或外部服务时，需要重新确认数据边界和成本。
- 效果测量口径变化后，历史数据不能直接混入新统计。

## 7. 风险控制

- 不允许绕过人工确认直接发布材料。
- 不允许提交未脱敏的内部数据。
- 不允许把系统建议分写成官方成绩。
- 不允许把模板示例中的空字段或待补项留在正式提交件中。
