# SAGE-VQ V12 独立 ICLR 风格评审

评审日期：2026-08-30

稿件：`papers/paper_zh_v12.md`

## 1. 论文概述

本文研究约 2.12 bpp 的 block-scaled shared-codebook VQ 中，冻结 scale 硬端点之后的 assignment 候选能否由局部二阶代理可靠排序。方法用真实 group scale、有限码字差分与 Linear 输入二阶矩定义对角局部输出曲率，并在四视图严格共识候选池中按最差一阶变化除以曲率代价排序。作者在 Llama-3.1-8B-Instruct 最后四层构造三种排序、四个相同 cardinality 的 hard set，共 12 次端到端验证。

结果显示，曲率排序相对 strict consensus 在 4/4 个预算上更好，但相对 aggregate first-order 仅 2/4 胜，未达到预注册 3/4 门槛。所有 hard set 都比冻结 source 差；最佳点 Macro 低 5.47 pp、balanced loss 高 18.31%。系统据此不访问候选 audit、不写 checkpoint、不运行正式测试，也不启动完整 assignment 训练。

## 2. 优点

### 2.1 可证伪问题与干预边界清楚

V12 没有把“用了 Hessian”包装成创新，而是在 V11 已排除单纯符号冲突后，只加入实际 scale、有限跳转大小和输入激活二阶矩。三个排序共享真实锚点与硬 cardinality，差异可归因于排序信息结构。预注册 3/4 胜负门槛避免结果出来后移动标准。

### 2.2 真实 hard set 比 soft surrogate 更可信

论文没有用定义候选的同一曲率分数自证有效，而是每次稀疏应用 assignment 后运行完整任务 validation，再精确恢复 source。曲率对共识 4/4 胜而对 aggregate 2/4 胜的混合结果被如实报告，比只展示最优预算更有说服力。

### 2.3 Claim 边界和数据治理优秀

作者明确 $q_i$ 只是对角化 Linear 输出二次代价，不是完整 Transformer Hessian；明确任务监督与 QTIP 设置不公平；明确 source 的 PPL/准确率不是 V12 新测量。Gate 失败后不读取候选 audit、不运行正式 test，是值得保留的实验治理实践。

### 2.4 负结果确实缩小机制空间

V10--V12 形成一条连贯排除链：聚合一阶不足、跨视图符号共识不足、独立候选对角曲率仍不足。曲率对共识稳定改善说明二阶信息不是完全无效；所有集合仍退化则把问题合理地推向非线性传播和集合交叉项。

## 3. 主要问题

### 3.1 仍没有可用的新压缩方法或 Pareto 点

最严重的问题没有改变：最终部署方法仍是先前的 scale-only checkpoint。Curvature probe 是诊断器，不是带来收益的算法。对于以模型压缩为目标的主会论文，候选排序优于另一个失败排序不足以替代最终 PPL/下游性能贡献。

### 3.2 “集合交互”仍主要是遗漏项解释

论文通过失败定位到 $\delta_i^\top H\delta_j$、跨层激活传播与非线性，但没有直接测量其中任何一项。大预算退化与交叉项累积相容，却也可能来自候选局部邻域质量、梯度任务偏置或层范围选择。因此“剩余瓶颈是集合交互”应保持为当前最强解释，而非已识别因果机制。

### 3.3 实验覆盖过窄

只有一个 8B instruct 模型、最后四层、一个固定 VQ 配置。12 个集合在单一 source 上的 matched 设计内部效度较高，但无法判断该边界是否跨模型、跨层或跨码本成立。没有一个正控制证明 $q_i$ 在简单线性/block reconstruction 目标上能达到理论预期，也削弱了“局部正确、全局失效”的直接证据。

### 3.4 与顶会压缩文献的性能关系仍弱

论文对 BRECQ/GPTQ/QTIP/PV-Tuning 的定位是准确的，但实验没有同协议的模块重构或集合条件优化基线。读者无法判断失败来自对角曲率近似太弱，还是 assignment-after-scale 本身几乎没有剩余自由度。

## 4. 次要问题

## 6. 决定

**Borderline Reject（5.5/10）**。

若以“极低比特 VQ assignment 代理失效研究”定位，论文的实验纪律和机制收缩达到较高水平；若以新压缩算法投稿，当前贡献仍不足，因为部署结果没有变化。接收所需的关键不是再增加一个逐候选分数，而是产生一个能够建模集合条件收益、并在真实 PPL/下游上改善 source 的方法。

## 7. 下一版本唯一值得做的方向

V13 应停止独立候选 ranking。唯一有机制依据的实验是小集合 sequential conditional gain：每一步先 hard apply 一个小批候选，用 block/layer 输出或端到端 held-out loss 估计在当前集合条件下的真实边际收益，再决定下一批。必须包含一个正控制：局部 $q_i$ 是否能预测 Linear/block reconstruction；若正控制通过而端到端失败，才直接证明传播缺口。若条件集合方法仍不能产生超过 source 的端点，应结束 assignment 主线，将其作为 scale-only 方法的边界分析而非继续迭代 selector。
