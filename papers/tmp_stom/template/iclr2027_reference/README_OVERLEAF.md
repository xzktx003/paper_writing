# ProFiMoE Overleaf package

Upload the accompanying ZIP file with **New Project -> Upload Project**. The archive already places `main.tex` at the project root.

Recommended Overleaf settings:

- Main document: `main.tex`
- Compiler: pdfLaTeX
- TeX Live version: latest available

Overleaf should run BibTeX automatically. If references initially appear as question marks, use **Recompile from scratch** once.

The manuscript is configured for anonymous ICLR 2027 review. Keep `\iclrfinalcopy` commented out until preparing a camera-ready version.

Orange `TBD` cells and the raster figures are intentional placeholders inherited from the current draft.
